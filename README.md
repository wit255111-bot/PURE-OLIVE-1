# PURE & OLIVE — Minimal & Clean Beauty E-Commerce Platform
### เว็บไซต์จำหน่ายสกินแคร์ เครื่องสำอางคลีนบิวตี้ และอุปกรณ์เสริมความงาม
*(โปรเจกต์พัฒนาระบบพาณิชย์อิเล็กทรอนิกส์เพื่อการศึกษา — Full-Stack Python Flask & SQLite)*

---

## 🌿 1. บทนำและแนวคิดของระบบ (Concept & Philosophy)

**PURE & OLIVE (เพียว แอนด์ โอลีฟ)** ได้รับการออกแบบภายใต้แนวคิด **Clean, Minimal & Botanical Beauty** เน้นความเรียบหรู อบอุ่น และเป็นธรรมชาติ ด้วยชุดโทนสี **ขาวอุ่น (Warm White) ผสานเขียวโอลีฟ (Olive Green) และเขียวเซจ (Sage Green)** 

ระบบถูกพัฒนาขึ้นเพื่อตอบโจทย์ผู้บริโภคยุคใหม่ที่ใส่ใจในสุขภาพผิว โดยเฉพาะกลุ่มผิวบอบบางและแพ้ง่าย (Sensitive Skin) ทุกสูตรปราศจากสารระคายเคือง (100% Clean, Vegan & Cruelty-Free)

---

## 🌟 2. ฟีเจอร์เด่นของระบบ (Key Features)

### 2.1 ระบบแบบทดสอบวิเคราะห์สภาพผิวอัจฉริยะ (Skin Quiz & Routine Builder)
- **Interactive Step Wizard**: ผู้ใช้ตอบคำถาม 3 ข้อ
  1. สภาพผิวปัจจุบัน (ผิวมัน, ผิวแห้ง, ผิวผสม, ผิวบอบบางแพ้ง่าย)
  2. ปัญหาผิวหลักที่กังวล (สิวและการคุมมัน, ผิวแห้งขาดน้ำ, ฟื้นฟูเกราะป้องกันผิว, ริ้วรอยยกกระชับ)
  3. สไตล์การดูแลที่ชื่นชอบ (Minimalist 3 สเต็ป หรือ Complete Ritual + บิวตี้ทูลส์)
- **Personalized Diagnostic Engine**: ระบบจับคู่และวิเคราะห์จัดรูทีนเช้า (Morning Routine) และรูทีนก่อนนอน (Night Routine) พร้อมเหตุผลประกอบ
- **1-Click Bundle Purchase**: ปุ่มสั่งซื้อทั้งเซตแนะนำลงตะกร้าในคลิกเดียว พร้อมรับส่วนลดพิเศษ 15% ทันที

### 2.2 แคตตาล็อกสินค้าและระบบตัวกรองละเอียด (Product Catalog & Filtering)
- แบ่งหมวดหมู่ชัดเจน:
  - **สกินแคร์ & ครีมบำรุง**: เจลล้างหน้า, โทนเนอร์, เซรั่มสควาเลน, มอยส์เจอไรเซอร์, ครีมกันแดด, ออยล์บำรุงผิว
  - **เครื่องสำอางคลีนบิวตี้**: คุชชั่นเซรั่มงานผิว SPF35, ลิปแอนด์ชีคบัตเตอร์ออร์แกนิก, บลัชออนเนื้อครีม, แป้งข้าวคุมมัน
  - **อุปกรณ์เสริมความงาม**: กัวซาหินหยกแท้ & ลูกกลิ้ง, แปรงแต่งหน้าใยมังสวิรัติ, แปรงล้างหน้าคลื่นโซนิค, เครื่องนวดผลักครีมประจุไอออนิก
- ตัวกรองแยกตาม **ปัญหาผิว (Acne, Barrier, Hydration, Aging, Brightening)**
- ระบบค้นหาอัจฉริยะ ค้นหาได้ทั้งชื่อภาษาไทย ภาษาอังกฤษ และส่วนผสมสำคัญ (Key Ingredients)
- ตัวเลือกการเรียงลำดับ: ความนิยม, ราคาต่ำ-สูง, ราคาสูง-ต่ำ, รีวิวสูงสุด, สินค้าใหม่

### 2.3 หน้ารายละเอียดสินค้าและระบบรีวิว (Product Details & Reviews)
- แสดงข้อมูลสเปกสินค้า ส่วนผสมเด่น (Key Ingredients) วิธีใช้งาน (How to Use) ปริมาณ และสถานะสต็อก
- **Customer Reviews with Skin Type Badges**: ระบบรีวิวที่แสดงสภาพผิวของผู้รีวิว (เช่น *"สภาพผิว: ผิวผสม แพ้ง่าย"*) ช่วยให้ลูกค้าตัดสินใจได้ง่ายขึ้น
- ฟอร์มให้ลูกค้าเขียนรีวิว ให้คะแนนดาว และระบุสภาพผิวได้จริง

### 2.4 ระบบตะกร้าสินค้าและคำนวณราคา (Cart & Checkout System)
- **Cart Slide-Over Drawer**: ตะกร้าสินค้าด้านข้างเปิด-ปิดสะดวก เพิ่ม/ลดจำนวนสินค้าได้แบบเรียลไทม์
- **Free Shipping Progress Bar**: แสดงแถบคำนวณยอดจัดส่งฟรีเมื่อช้อปครบ 990 บาท
- **Coupon System**:
  - `CLEAN10` : ส่วนลด 10% ทั้งตะกร้า
  - `OLIVE50` : ส่วนลด 50 บาท
  - `ROUTINE15` : ส่วนลดเซตรูทีน 15%
- ช่องทางการชำระเงิน:
  - PromptPay QR Code (พร้อมระบบจำลองการสร้าง QR Code และยืนยันการชำระเงินอัตโนมัติ)
  - บัตรเครดิต/เดบิต
  - เก็บเงินปลายทาง (COD)
- ออกใบเสร็จรับเงิน (Receipt) พร้อมปุ่มสั่งพิมพ์ (Print-friendly format)

### 2.5 ระบบจัดการหลังบ้านสำหรับแอดมิน (Admin Dashboard)
- เข้าใช้งานได้ที่ URL: `/admin`
- สรุปสถิติแบบเรียลไทม์: ยอดขายรวม, จำนวนออเดอร์, จำนวนสินค้า, แจ้งเตือนสินค้าสต็อกน้อย
- ตารางตรวจสอบคำสั่งซื้อล่าสุด พร้อมฟังก์ชันอัปเดตสถานะจัดส่ง (ชำระแล้ว -> กำลังจัดส่ง -> เสร็จสมบูรณ์)
- ตารางตรวจเช็คสต็อกสินค้า และฟอร์มเพิ่มสินค้าใหม่เข้าร้านพร้อมอัปโหลดรูปภาพและข้อมูล

## 🚀 3. วิธีการรันโปรเจกต์ (Quick Start Guide)

### ขั้นตอนที่ 1: ติดตั้งไลบรารีที่จำเป็น
เปิดโปรแกรม Terminal หรือ PowerShell ในโฟลเดอร์ `C:\075`:
```bash
python -m pip install flask python-docx
```

### ขั้นตอนที่ 2: รันเซิร์ฟเวอร์
```bash
python app.py
```

### ขั้นตอนที่ 3: เปิดใช้งานเว็บไซต์
เปิดเว็บเบราว์เซอร์ไปที่:
```
http://127.0.0.1:5000
```
